A backend-focused project for building a URL shortening and universal-linking service with REST APIs, persistent storage, redirection, and link-management workflows.

The project explores practical backend concerns including unique short-code generation, expiration, API design, database-backed persistence, health checks, documentation, caching-oriented architecture, and scalable redirection paths.
